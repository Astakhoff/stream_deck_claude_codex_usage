# Branding

The product name is **Claude & Codex Weekly Usage**.

The original logo combines an outlined key, the letters **AI**, and a remaining-capacity bar. It is designed for the monochrome outline style of Stream Deck's action list. The artwork uses vector paths rather than fonts, so the monogram renders consistently on other systems.

## Source artwork

- [`ai-usage.svg`](../assets/brand/ai-usage.svg): category and plugin identity.
- [`weekly-action.svg`](../assets/brand/weekly-action.svg): weekly-capacity action.
- [`reset-action.svg`](../assets/brand/reset-action.svg): saved-reset action.

Category and action artwork is white on a transparent background so Stream Deck can adapt it to its UI theme. Category PNG exports are 28 × 28 and 56 × 56 pixels. Action PNG exports are 20 × 20 and 40 × 40 pixels. The plugin identity is also exported at 256 and 512 pixels. The dark tile in the README is a presentation background, not part of the transparent category icon.

The live key displays retain their existing percentage, countdown, and reset-count layouts. This branding update changes the action-list identity and plugin name, not the meaning of the displayed readings. Existing plugin and action UUIDs remain stable.

Artwork is provided under the repository's MIT license. This is an independent identity, not an official Anthropic, OpenAI, or Elgato logo.
